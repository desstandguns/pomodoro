# ポモドーロタイマー

スマホのホーム画面に置いて使える、シンプルなポモドーロタイマーです。

**アプリを開く：https://desstandguns.github.io/pomodoro/**

## できること
- 作業時間を **3分・5分・25分・45分・60分** から選べます。作業と休憩を自動でくり返し、4回ごとに長い休憩があります
- 時間になったら、**画面にさわるまで音でお知らせ**します（最大1分）。Android は震えます
- 「早めに完了」「休憩をとばす」で、予定より早く次に進めます
- **いまやること**をメモしておくと、終わった作業と一緒に記録に残ります
- **記録**：この7日間の回数のグラフ、集中した合計の分数、続けている日数、最近の作業
- **設定**（右上の歯車）：自動で次に進むか、音の種類と大きさ、作業中の環境音（雨・風）、1日の目標、記録のバックアップ
- アプリを閉じても、開き直すと続きから動きます。ネットがなくても開けます

## ホーム画面に追加する
- **iPhone（Safari）**：上のアドレスを開き、下の共有ボタン（□に↑）→「ホーム画面に追加」
- **Android（Chrome）**：上のアドレスを開き、右上の「︙」→「ホーム画面に追加」または「アプリをインストール」

## 知っておくこと
- お知らせの音は、**アプリの画面を開いているとき**に鳴ります。画面を消したり、ほかのアプリを使ったりしていると鳴りません
- マナーモードのときは、音が聞こえないことがあります。「音を試す」で確かめられます
- 記録はそのスマホの中にだけ保存されます。機種を変えるときは、設定の「書き出す」で保存しておけます

## 作っている人向け
- `index.html`：アプリ本体（HTML・CSS・JavaScript がすべて入っています）
- `push.js` / `push-server/`：画面を消していても届く通知の仕組み（準備中）
- `tests/`：自動テスト（`node --test tests/`）
- `HANDOFF.md`：開発の引き継ぎメモ
